# 论文研究技能可视化工作流

本文档描述 `paper-research-workflow` 从“输入论文”到“知识库与创新挖掘”的完整工作流。

## 总流程

```mermaid
flowchart TD
    A[用户调用 paper-research-workflow] --> B{是否已配置默认工作区?}
    B -->|否| C[询问用户选择长期论文库目录]
    C --> D[setup 保存 .paper-workspace.json]
    B -->|是| E[接收本地 PDF 路径]
    D --> E

    E --> F{是否优先使用 MinerU?}
    F -->|否| G[轻量提取 pdftotext 或 pypdf]
    F -->|是| H{MinerU 后端选择}

    H -->|custom| I[MINERU_TO_MD 自定义 wrapper]
    H -->|standard-cloud| J[高质量云 MinerU]
    H -->|local| K[本机 mineru]
    H -->|agent-cloud| L[轻量云 MinerU]
    H -->|auto| M[按 custom -> token -> local -> agent-cloud 顺序自动选择]

    M --> I
    M --> J
    M --> K
    M --> L

    G --> N[生成 extracted/_incoming]
    I --> N
    J --> N
    K --> N
    L --> N

    N --> O[text.md tables.md equations.md figures.md manifest.json]
    O --> P[生成 paper_id]
    P --> Q[自动分类 classify_text]
    Q --> R[归档 PDF 到 papers/by-domain 和 papers/by-year]
    R --> S[写入 knowledge/papers orlt paper-id.json]
    S --> T[更新 state/papers.json]

    T --> U{用户要哪种阅读输出?}
    U -->|通俗解释| V[生成 knowledge/cards orlt paper-id.md]
    U -->|专家阅读| W[生成 knowledge/expert-readings orlt paper-id.md]
    U -->|复现计划| X[生成 knowledge/reproductions orlt paper-id.md]
    U -->|创新挖掘| Y[检索 knowledge/papers 并生成 knowledge/innovations orlt innovation-id.md]

    V --> Z[同步更新 knowledge/papers orlt paper-id.json]
    W --> Z
    X --> Z
    Y --> Z
```

## 产物流向

```mermaid
flowchart LR
    A[输入 PDF] --> B[papers/by-domain orlt paper-id.pdf]
    A --> C[papers/by-year orlt paper-id.pdf]
    A --> D[extracted orlt paper-id]

    D --> D1[text.md]
    D --> D2[tables.md]
    D --> D3[equations.md]
    D --> D4[figures.md]
    D --> D5[manifest.json]

    D1 --> E[knowledge/papers orlt paper-id.json]
    D2 --> E
    D3 --> E
    D4 --> E
    D5 --> E

    E --> F[knowledge/cards orlt paper-id.md]
    E --> G[knowledge/expert-readings orlt paper-id.md]
    E --> H[knowledge/reproductions orlt paper-id.md]
    E --> I[knowledge/innovations orlt innovation-id.md]
    E --> J[state/papers.json]
```

## MinerU 云端细化流程

```mermaid
flowchart TD
    A[standard-cloud] --> B{是否已有 MINERU_TOKEN 或已保存 token?}
    B -->|否| C[提示先运行 configure-mineru]
    B -->|是| D[POST file-urls/batch]
    D --> E[获取 batch_id 和 upload_url]
    E --> F[低层 HTTPS PUT 上传 PDF 到 OSS 预签名地址]
    F --> G[GET extract-results/batch orlt batch_id]
    G --> H{是否完成?}
    H -->|否| G
    H -->|是| I[下载 full_zip_url 或 markdown_url]
    I --> J[解压并归一化为 text.md 等文件]
```

## 语言模式

```mermaid
flowchart TD
    A[默认中文输出] --> B{用户是否显式切换?}
    B -->|切换英文 / English mode| C[后续用户可见输出改为英文]
    B -->|切换中文 / Chinese mode| D[后续用户可见输出改为中文]
    B -->|未切换| E[继续默认中文]

    C --> F[通俗解释]
    C --> G[专家阅读]
    C --> H[复现计划]
    C --> I[创新简报]

    D --> F
    D --> G
    D --> H
    D --> I
    E --> F
    E --> G
    E --> H
    E --> I
```

## 说明

- `knowledge/papers/<paper-id>.json` 是核心机器可读主记录。
- `cards`、`expert-readings`、`reproductions`、`innovations` 是面向人阅读的 Markdown 产物。
- `state/papers.json` 记录每篇论文已经完成到哪个阶段。
- 多篇论文共享同一个长期工作区，后续新论文进入时会在各自目录下新增同级文件。
